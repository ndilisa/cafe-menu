# Cafe Menu
A simple Cafe Menu webpage built using HTML and CSS. This project displays a clean, responsive menu for a fictional coffee shop, featuring different coffee drinks and desserts.  The goal of this project was to practice basic web development concepts, including semantic HTML structure, CSS styling, layout control, and responsive design principles.

📌 Features
- Structured HTML5 semantic layout
- Styled menu interface using CSS
- Centered menu container with responsive width
- Coffee and dessert sections with pricing
- Background image for visual aesthetics
- Styled links with hover, visited, and active states
- Footer with attribution and external link

🛠️ Technologies Used
- HTML5
- CSS3
